Revised test-ready build

Version 2.0.0 failed during runtime setup on Windows. Version 2.0.1 removes PowerShell and preserves Windows security settings.

Windows installation, runtime download, desktop login, module display and uninstall have not been tested on Windows. Password credentials were verified separately. Please test on your own Windows computer before depending on it for daily work.

Before installing

  • Windows 10 version 1803 or newer / Windows 11 x64 required. No PowerShell script or policy change.
  • Native setup downloads about 158 MB from the official Electron release, verifies SHA-256 and size, and extracts using Windows built-in tar.exe.
  • Internet is needed during installation and for cloud records.
  • Unsigned, per-user installer. No administrator rights, auto-start, updater or background service.
  • Do not disable antivirus or other security protections. If Windows blocks setup, stop and ask for help.
  • Google/Gmail authorization remains on the website. This is not an offline ERP or audited accounting system.
