UDECS Management

Windows x64 online installer, version 2.0.0. Admin and Founder/HR use their separate UDECS app passwords. Existing Firebase records stay in the cloud.

Download Windows installer (4 MB)

Test-ready build

Windows installation, runtime download, desktop login, module display and uninstall have not been tested on Windows. Password credentials were verified separately. Please test on your own Windows computer before depending on it for daily work.

Before installing

  • Windows x64 and Windows PowerShell 5.1 or later required.
  • Setup downloads about 158 MB from the official Electron release and verifies SHA-256 before installing.
  • Internet is needed during installation and for cloud records.
  • Unsigned, per-user installer. No administrator rights, auto-start, updater or background service.
  • Do not disable antivirus, script policy or other security protections. If Windows blocks setup, stop and ask for help.
  • Google/Gmail authorization remains on the website. This is not an offline ERP or audited accounting system.
